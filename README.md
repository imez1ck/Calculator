# Java Console Application

A simple console application written in Java. This project was created to practice Java fundamentals, object-oriented programming, and working with user input.

## Features

- **Calculator** — performs basic mathematical operations.
- **Number Comparison** — compares three numbers and finds the largest one.
- **Even or Odd Checker** — checks whether a number is even or odd.
- **Main Menu** — allows users to select different features or exit the application.

## Technologies

- Java
- Scanner
- Conditional statements (`if`, `else`, `switch`)
- Loops (`while`, `for`)
- Methods and classes
- Basic object-oriented programming (OOP)

## Project Structure

```text
JavaProject/
├── Main.java
├── Calculator.java
├── Comparison.java
└── Cheacker.java
```

## How to Run

1. Make sure you have the Java Development Kit (JDK) installed.
2. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

3. Open the project in your IDE (for example, IntelliJ IDEA).
4. Run `Main.java`.
