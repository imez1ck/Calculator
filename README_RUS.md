# Java Console Application

Небольшое консольное приложение на Java, созданное в процессе изучения основ языка и объектно-ориентированного программирования (ООП).

## Возможности

Приложение содержит главное меню с несколькими инструментами:

- **Calculator** — калькулятор с базовыми арифметическими операциями.
- **Comparison** — сравнение трёх чисел и поиск наибольшего.
- **Checker** — проверка числа на чётность.
- **Main Menu** — главное меню для навигации между функциями и выхода из программы.

## Технологии

- Java
- Scanner (`java.util.Scanner`)
- Условные конструкции (`if`, `else`, `switch`)
- Циклы (`while`, `for`)
- Методы и классы
- Основы ООП

## Запуск проекта

1. Установите JDK.
2. Склонируйте репозиторий:

```bash
git clone YOUR_REPOSITORY_URL
```

3. Откройте проект в IntelliJ IDEA.
4. Запустите `Main.java`.

## Цель проекта

Закрепление базовых знаний Java на практике: работа с переменными, условиями, циклами, методами, классами и пользовательским вводом.

## Статус

В разработке. Проект постепенно расширяется по мере изучения Java.
